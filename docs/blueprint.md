# **App Name**: Verse Scribe

## Core Features:

- Multi-System Character Creation: Allows users to create new character sheets, choosing between DnD 5e or Dark Heresy rulesets.
- Character Data Management: Store and retrieve character sheet data from the database, specific to the chosen game system.
- Interactive Character Sheet Editor: A UI for editing character attributes, skills, inventory, and other relevant details dynamically.
- Character Sheet Viewer: Display a clean, organized view of the created character sheets for review or gameplay.
- AI Character Concept Assistant Tool: Generate initial character concept suggestions, including brief backstories, personality traits, and starting gear, tailored to the chosen game system.
- User Authentication: Allow users to create accounts, log in, and securely access their stored character sheets.

## Style Guidelines:

- Primary color: A muted arcane blue (`#707ED2`) to evoke both fantasy magic and futuristic interfaces, standing out on a dark background.
- Background color: A very dark, subtle blue-gray (`#1A1C23`), providing a sophisticated and immersive canvas for character sheets.
- Accent color: A vibrant cyan-blue (`#269ED9`) for interactive elements, highlights, and important notifications, ensuring high visibility.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, slightly technical feel, suitable for titling and game system identity.
- Body font: 'Inter' (sans-serif) for exceptional legibility and neutrality, ideal for displaying detailed character sheet data.
- Use sharp, distinct icons that blend fantasy motifs (swords, shields, spellbooks) with sci-fi elements (gears, digital symbols, energy bolts) to support both game systems.
- Implement a modular, responsive grid-based layout for character sheets, ensuring optimal readability and ease of data entry on various screen sizes, with clearly defined sections for attributes, inventory, and skills.
- Subtle, smooth transition animations for form submissions, data loading, and navigation between different sections of the character sheet, enhancing user feedback without being distracting.
